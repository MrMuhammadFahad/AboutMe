Portfolio of Muhammad Fahad bin Sajjad
--------------------------------------
Open index.html in any browser. No build step is required. A language switcher
lets visitors choose French; English is the default.

Files
  index.html   page content
  style.css    all styling (black and white)
  translations.js English and French page text and language switching
  assets/      profile photo

To publish for free: upload this folder to GitHub Pages, Netlify or Cloudflare Pages.
Fonts (Bricolage Grotesque and Inter) are bundled in assets/fonts, so it works offline.
