--------------------------------------
Open index.html in any browser. No build step, no JavaScript.

Files
  index.html   page content
  style.css    all styling (black and white)

To publish for free: upload this folder to GitHub Pages, Netlify or Cloudflare Pages.
Fonts (Bricolage Grotesque and Inter) are bundled in assets/fonts, so it works offline.
